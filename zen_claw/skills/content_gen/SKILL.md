# content_gen

Use this skill when the user needs draft marketing copy for a specific channel, product, or audience.

## Inputs to collect

- industry
- channel
- product_name
- audience
- style
- key_points
- length

## Working style

1. Clarify the delivery channel and output format first.
2. Keep the draft grounded in user-provided facts; do not invent product claims.
3. If local knowledge exists, read relevant material before drafting.
4. Produce 2-3 distinct variants when the user asks for options.
5. Flag any statements that should be reviewed by compliance before publishing.

## Output shape

- brief strategy note
- primary draft
- optional alternates
- review notes for compliance-sensitive claims
